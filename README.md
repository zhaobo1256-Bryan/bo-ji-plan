# 薄肌计划

目标：12 周减脂增肌（"薄肌"）。

## 手机日志 App
- 功能：每日训练记录、拍照估算热量、身体数据、体重档案、AI 周报和计划调整
- 数据存在 App 自己的数据库里（只有本人可读写），不在这个文件夹
- 源码：`app/薄肌日志.html`（在 claude.ai 作为 Artifact 发布运行）
